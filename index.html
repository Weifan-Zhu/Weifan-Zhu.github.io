03 / The AI project

Role: project lead and system architect · AI-assisted coding during development

Literature AI Assistant

This project began with a practical problem: screening new condensed-matter papers takes time. The assistant watches arXiv, reads PDFs and figures, and gives the group a searchable web workspace. I designed the workflow, system architecture, filtering logic, and validation process, and continue to handle deployment and maintenance.

  • Each day it checks cond-mat.str-el and cond-mat.mtrl-sci, screens new papers with about 50 weighted physics keywords, downloads the PDFs, and publishes notes. A custom arXiv crawler keeps the fetch success rate above 99%.
  • DeepSeek writes structured summaries. Gemini handles longer multimodal analysis, Kimi reads figures, and users can ask questions about a paper inside the site.
  • The web app uses Python, Flask, Jinja2, PyMuPDF, and a 13-table SQLite database. It now holds 358 papers, 3,814 figures, and 358 AI summaries for 13 registered users.
  • As the collection grew, regression tests and repair tools became part of the system: a 142-PDF caption test reached zero misclassifications, and one repair run fixed 544 records and removed 820 orphaned images.
